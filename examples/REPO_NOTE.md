# This folder is what your OUTPUT should look like

The files here are **reference examples of the correct output** of running `prompts/one-shot-prompt.md`. Each is a single self-contained HTML file.

When you (the AI) complete the user's PDF → HTML conversion, the result should be **one HTML file** structurally similar to the examples in this folder.

The result must **not** be a new toolkit, multiple templates, or a ZIP archive. See `../AGENTS.md`.
